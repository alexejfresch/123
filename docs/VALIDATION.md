# Проверка перед выпуском

Результат в текущей Linux-среде (25.10.2026): **40 тестов пройдено**, ошибок нет; установка из `requirements.lock` повторно выполнена, `pip check` успешен, создание и закрытие окна через `--smoke-test` успешно. Дополнительно скачаны с проверкой SHA256 50 пакетов для Windows x64/Python 3.12; зависимости проверены по METADATA с маркерами Windows. Это проверка доступности и совместимости пакетов, а не выполненная сборка EXE.

Локальный автоматический набор использует только искусственные данные. `pytest` включает проверки бизнес-правил, SQLite, XLSX, Google API через подменённый транспорт и создание настоящих Qt-окон в режиме offscreen.

Покрываются: одна/три пары; УИК только в одном источнике; отсутствующий/пустой Excel; смена состава и названий столбцов; несколько отправок; поздняя ошибка и предыдущее подтверждение; изменение подтверждённой записи; пробелы; отсутствие сети; прерывание чтения; откат транзакции; перенос папки; экспорт без чтения/проверки Google; неоднозначное время; повторные ID; перестановка строк; исчезновение отправки; конкурирующее чтение; фоновые задачи и таймер интерфейса.

Различайте три уровня проверки:

1. **Локальные тесты Linux:** выполняются в облачной среде и подтверждают обработку искусственных данных и запуск окна.
2. **Живая интеграция Google:** требует Desktop OAuth client JSON, доступного защищённого хранилища, браузера и таблицы с тестовыми строками. Нужны первоначальное чтение, повторное чтение, исправление строки, ручное подтверждение и повторный вход. В облачной среде без пользовательской авторизации эта проверка не выполняется.
3. **Windows:** запустите `packaging/build-windows.ps1` или workflow Windows. Проверьте EXE на компьютере без Python, OAuth в браузере, работу Credential Manager, перенос приложения, чтение Excel и экспорт в каталог с кириллицей. Подготовленный скрипт сам по себе не доказывает успешную сборку или запуск на Windows.

Перед передачей пользователям подтвердите пункт 2 и пункт 3. Публичный выпуск и публикация окружения не выполняются автоматически.
