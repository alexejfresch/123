# Инструкция пользователя

## Первый запуск и обновление 1.0.1

Вкладки открываются и без проекта. Для подключения источников нажмите «Новый проект»: после этого поля и кнопки работы с данными станут доступны. Интерфейс использует светлый фон с тёмным текстом независимо от темы Windows.

При обновлении закройте старую программу, распакуйте ZIP в отдельную папку и перенесите свою папку `data` из старой папки приложения в новую, рядом с `UIK-Reconcile.exe`. Сам EXE и `_internal` используйте из новой сборки. Формат SQLite и настройки в 1.0.1 не изменяются.

## Искусственные примеры для знакомства

В `examples/` находятся `Excel_пример.xlsx` и `Google_пример.csv`. Импортируйте CSV в отдельную Google Таблицу, выберите формат времени `ISO`, сопоставьте «Номер УИК» → «Номер участка» и «Число избирателей» → «Избирателей». ID и время задаются одноимёнными столбцами CSV. Это только искусственные тестовые данные.

Ожидаемое поведение: отправки send-001, send-002 и send-003 совпадут; send-004 даст позднее расхождение для УИК 291; у send-005 отсутствует Excel. Подтвердите send-001 и проверьте, что при экспорте выбирается она, а send-004 отображается предупреждением. Чтобы увидеть данные уникального столбца Excel, включите его в разделе экспорта.

## Первое подключение

1. Запустите `UIK-Reconcile.exe`. Нажмите «Новый проект» и задайте название.
2. Выберите рабочую пару. Первая пара включена; вторую и третью включайте в «Источники данных» только при необходимости. В проекте остаётся хотя бы одна активная пара.
3. Если Excel есть, нажмите «Импортировать Excel», выберите файл, лист и столбец номера УИК. Поддерживаются XLSX и XLSM; макросы не выполняются. Заголовки находятся в первой строке, они должны быть непустыми и уникальными. В Excel для одной УИК должна быть одна строка; неоднозначные повторы требуют уточнения исходного файла.
4. Импорт создаёт внутреннюю копию. После успешного импорта исходный файл можно переместить. Для обновления Excel выполните новый импорт. Пустой или отсутствующий Excel не препятствует чтению Google.
5. Вставьте ссылку Google Таблицы. Введите название листа и нажмите «Сохранить источник».
6. Нажмите «Войти в Google» и выберите OAuth client JSON для приложения типа **Desktop app**. Авторизация открывается в браузере. После входа можно нажать «Получить листы», выбрать нужный лист и сохранить источник.
7. Нажмите «Прочитать структуру». Это получает столбцы для настройки; полноценный снимок отправок появится после «Проверить сейчас».
8. В разделе «Сопоставление полей» выберите столбцы Google: номер УИК, уникальный ID отправки и исходное время отправки. Укажите формат времени. Например, `25.10.2026 12:30:00` соответствует `%d.%m.%Y %H:%M:%S`; для `2026-10-25T12:30:00+05:00` выберите `ISO`. Без часового пояса время трактуется как местное время источника; все строки должны использовать единый подход. Время чтения отдельно хранится в UTC и не заменяет время отправки.
9. Для каждого общего поля Excel явно выберите соответствующее поле Google. Пустой выбор означает отдельное поле Excel. Автоматического смыслового сопоставления нет. Одно поле Google не может соответствовать нескольким полям Excel.
10. Сохраните схему и нажмите «Проверить сейчас». Все отправки листа будут сохранены и проверены.

Если Excel отсутствует, общие поля можно настроить после его импорта; до этого все столбцы Google сохраняются и доступны для экспорта вручную подтверждённых отправок.

## Подготовка Google OAuth

В Google Cloud Console создайте проект, включите Google Sheets API, настройте OAuth consent screen и создайте OAuth Client ID типа Desktop app. В режиме тестирования добавьте свой аккаунт в тестовые пользователи. Скачайте JSON на компьютер и выберите его через кнопку входа. Используйте аккаунт с правом чтения нужной таблицы. Программа не запрашивает право изменения таблиц.

Пароль Google не вводится в программу. Токены хранятся в Диспетчере учётных данных Windows через `keyring`, отдельно от рабочей базы. Если защищённое хранилище недоступно, авторизация завершается ошибкой, текстового запасного хранилища нет. Для отключения доступа отзовите разрешение приложения в настройках аккаунта Google. На новом компьютере потребуется повторный вход.

Нужны доступ к `accounts.google.com`, `oauth2.googleapis.com` и `sheets.googleapis.com`, а также локальный обратный вызов браузера во время авторизации.

## Проверка и история

Главная сводка объединяет УИК всех активных пар. Можно фильтровать по УИК, паре, результату и подтверждению. Двойной щелчок открывает историю. Раздел «Проверка данных» выполняет локальную сверку без повторного чтения Google.

Обрезаются только пробелы по краям значения. `305` и ` 305 ` совпадают, но `0305` и `305`, `1 000` и `1000` не приводятся друг к другу. Исходные значения отображаются в истории. Числовые, логические и статистические дополнительные проверки не добавляются.

В истории каждая отправка определяется выбранным ID. Повторное чтение неизменённых данных не создаёт дубликатов. При изменении содержимого сохраняется новая версия. Предыдущая версия остаётся для аудита, но экспортировать её вместо актуальной версии того же ID нельзя. Только изменения внешних пробелов не снимают подтверждение. Изменение другой отправки не затрагивает остальные подтверждения.

Перестановка строк не меняет ID. Исчезнувшие из источника отправки остаются в локальной истории; при экспорте подтверждённой исчезнувшей отправки будет предупреждение. Если ID повторяется или время нельзя разобрать, чтение не заменяет предыдущий успешный снимок и показывает ошибку.

При одинаковом времени двух отправок одной УИК порядок неоднозначен. Экспорт этой УИК требует явного включения настройки «При одинаковом времени использовать порядок строк Google». По умолчанию это правило выключено.

Изменения структуры показываются в разделе сопоставления. Исчезнувшие поля требуют ручной корректировки схемы. Заменить документ, лист, столбец ID или столбец УИК в паре с историей нельзя: создайте новый проект, чтобы не смешать разные источники и идентификаторы. Формат времени можно исправить, если сохранённые значения разбираются новым форматом.

## Подтверждения

Выберите актуальную отправку в разделе «Подтверждения». Кнопка подробностей открывает её исходные значения, Excel и расхождения. Совпадение не означает автоматического подтверждения.

Расхождения и отсутствие Excel разрешается подтверждать вручную: программа задаёт дополнительный вопрос и сохраняет решение в журнале. При невозможности сопоставления сначала нужно исправить схему. Изменение нормализованного содержимого отправки автоматически снимает её подтверждение; потребуется повторное решение. Подтверждение можно снять вручную.

## Автоматическое чтение

В «Настройки» включите автоматическое чтение и задайте интервал от 10 секунд. Настройка отдельная для каждой пары. Таймер обслуживает все включённые пары всех проектов, даже если на экране выбран другой проект. Одновременное чтение одной пары исключено. После запуска программы следующее чтение планируется через установленный интервал. При сетевой ошибке прежний снимок остаётся доступным; следующая попытка выполняется по таймеру.

## Экспорт

В «Экспорт» отметьте уникальные поля Excel текущей пары и сохраните выбор. Повторите для других пар. Общие поля идут в порядке столбцов Excel, затем уникальные Google, затем выбранные уникальные Excel. Для общего поля экспортируется исходное значение подтверждённой отправки Google; исходное значение Excel остаётся в локальной истории/снимке для сравнения. Это относится и к вручную подтверждённым расхождениям.

Нажмите «Предпросмотр и экспорт всего проекта». Для каждой УИК каждой активной пары выбирается отправка с самым поздним исходным временем среди подтверждённых актуальных версий. Более поздняя ошибочная или другая неподтверждённая отправка не заменяет выбранную — о ней появляется предупреждение.

Проверьте строки, время последнего успешного чтения и предупреждения. Сохраняется именно показанный предпросмотр: экспорт не обращается к Google, не выполняет новую сверку и не меняет подтверждения. Каждая пара получает отдельный лист; лист «Сведения» содержит время чтения и предупреждения. Без подтверждений экспортируемых строк нет. Строки, похожие на формулы Excel, записываются как текст.

## Перенос и восстановление

Закройте программу и скопируйте **всю** папку приложения вместе с `data/`. Не копируйте работающую SQLite-базу отдельно: рядом могут находиться файлы WAL. В `data/` находятся база, настройки, исходные значения, история и внутренние копии Excel. Автоматическое резервное копирование не реализуется.

После аварийного завершения SQLite восстанавливает завершённые транзакции. Прерванное чтение отмечается в журнале как прерванное, а не успешное. Старый успешный снимок остаётся доступным. Одну рабочую папку нельзя открыть двумя экземплярами одновременно.

Если папка недоступна для записи, перенесите приложение из защищённого каталога. Опытные пользователи могут указать другую рабочую папку аргументом `--data-dir "D:\Данные сверки"`.
